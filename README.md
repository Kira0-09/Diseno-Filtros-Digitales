# Diseño y análisis de filtros digitales

## Descripción
Este proyecto tiene como objetivo diseñar e implementar filtros digitales pasa bajos, pasa altos y pasa bandas utilizando Python.

## Herramientas utilizadas
- Python
- NumPy
- Matplotlib
- SciPy
- Google Colab

## Filtros implementados
1. Filtro pasa bajos Butterworth.
2. Filtro pasa altos Butterworth.
3. Filtro pasa bandas Butterworth.
4. Filtros FIR con ventana Hamming.

## Procedimiento
Se generó una señal compuesta por diferentes frecuencias y ruido blanco. Posteriormente, se diseñaron y aplicaron filtros digitales para observar sus efectos en el dominio del tiempo y de la frecuencia.

## Resultados
Se comprobó que cada filtro permite conservar determinadas frecuencias y atenuar otras, dependiendo de sus parámetros de diseño.

## Conclusión
Los filtros digitales son herramientas importantes para el procesamiento de señales, ya que permiten reducir el ruido y seleccionar componentes específicos de frecuencia.
